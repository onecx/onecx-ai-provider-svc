== MCP tool OneCX coordinates

Each MCP tool carries an `external` flag and optional OneCX coordinates (`productName`, `appId`).

* `external=true` (default) — the MCP server is outside OneCX; `productName` and `appId` are cleared and not required.
* `external=false` — the MCP server is internal; `productName` and `appId` are **required** and identify the OneCX product/application that holds the tool's permissions. Create and update requests for internal tools without both coordinates are rejected with `400 MISSING_TOOL_COORDINATES`.

=== Migration note

The `2026-11-16-tool-external` change set adds the `external` column with `defaultValueBoolean=true`, so every existing tool row becomes external (no OneCX permission coverage). The `2026-11-16-tool-product-app` change set adds nullable `product_name` and `app_id` columns, so existing rows have null coordinates. Existing tools can be updated without supplying coordinates because they default to external. Operators who want an existing tool to be internal must set `external=false` and supply `productName` and `appId` in an update request.

== Helm

{helm-registry}[Link to Helm registry]

.Default values in {helm-file}
[source,yaml]
----
app:
  name: svc
  image:
    repository: "onecx/onecx-ai-provider-svc"
    tag: 999-SNAPSHOT
  db:
    enabled: true
  operator:
    keycloak:
      client:
        enabled: true
        spec:
          kcConfig:
            defaultClientScopes: [ ocx-tn:read, ocx-agent:read, ocx-agent:write ]
    microservice:
      spec:
        description: OneCX AI Provider Backend Service
        name: OneCX AI Provider SVC
----
